# DataVertex's Candidate Sourcing API Developer Documentation

The DataVertex Candidate API is a unified API for comprehensive, compliant access to rich candidate data and AI-powered talent search capabilities.

With a single integration, you gain access to 800M+ professional candidate profiles sourced from a global network of aggregated data providers, including verified contact information, work history, skills, education, certifications, and industry-specific data. The API is designed to help recruiting platforms, AI recruiting agents, staffing products, and internal talent systems build sourcing, matching, enrichment, and outreach workflows faster.

In addition to structured candidate search, the DataVertex API supports AI-powered search experiences that enable users to discover talent using natural language queries, semantic search, contextual search, helping teams surface more relevant candidates beyond traditional keyword filtering.

## What You Can Build with the API

The DataVertex Candidate API enables teams to power workflows and product features such as:

### Candidate Sourcing

Search and discover candidates using structured filters including job title, skills, location, seniority, education, industry, employer, and more.

### AI-Powered Talent Search

Enable natural language and semantic candidate search experiences, allowing users to describe ideal candidates or share job descriptions instead of relying only on Boolean or keyword searches.

### Candidate Matching & Recommendations

Build AI-driven matching and recommendation systems that identify relevant candidates based on job descriptions, hiring intent, or contextual fit.

### Verified Contact Lookup

Retrieve verified email addresses and phone numbers to support outreach and engagement workflows.

### Candidate Data Enrichment

Enhance existing candidate records with updated employment history, skills, certifications, social links, and contact data.

### Talent Pipeline Refresh & Rediscovery

Keep candidate databases up to date with refreshed profile data, job changes, and updated contact information. Rediscover and re-engage with candidates already in your recruiting system.

### Outreach & Engagement Workflows

Inject candidate data into ATS, CRM, sequencing, and outreach platforms to support multi-channel recruiting workflows, including emailing, texting, WhatsApp, calling, etc.

### AI Recruiting Agents & Copilots

Power AI recruiting assistants and autonomous sourcing workflows with real-time candidate retrieval, enrichment, and search capabilities.
